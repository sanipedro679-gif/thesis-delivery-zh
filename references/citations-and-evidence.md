# 引文与证据

每篇来源用稳定 `id` 标识，排序变化仅更新 `number`。记录原始书目信息、来源类型、允许用途、指定状态及使用位置。书目去重先比 DOI/题名/作者年份，版本差异需人工决定；程序只自动报告完全相同条目，不能据未发现重复认定已彻底去重。

`evidence` 分开记录：

- `metadata`: `verified/pending`；独立来源定位 `metadata_locator`，核验日期、方法和说明。
- `access`: `record/abstract/fulltext`；仅表示取得资料的程度。
- `read`: `none/abstract/relevant_parts/fulltext`；不因下载文件而自动升级。
- `claim_support`: `checked/pending`；`claims` 逐处保存正文位置、论点、原文定位、支持范围和核对结论。

只有逐处对应原文后才能写 `checked`。DOI 可解析、官网有记录、读过全文都不自动证明论点被支持。核验脚本只读取台账，不联网验证这些记录是否真实。原摘要支撑的概括应限于摘要；精确效应、因果、公司事实须回到相应原文与原始资料。

## 顺序编码

1. 明确全文引用范围和文献表边界。学校表格模板中正文可能跨多张表；合并单元格不能重复扫描，文献表不能进入首次引用扫描。
2. 按实际文档顺序，第一篇首次引用为 `[1]`，重复出现仍用原号；区间引文应展开核对。
3. 建立稳定 ID 到新编号映射，一次性同步正文、表和台账。禁止逐个字符串替换造成编号碰撞。首版工具只审查，改号须另存副本并复查。
4. 检查缺项、未引用、重复条目、语言分组及数量。数据资料与学术文献分开计数，类型标记只作程序初筛，人工判断其学术适格性。
5. 字段、脚注、文本框、修订或作者年份制不在数字引文自动检查覆盖内，应补充真实工具检查。

文献综述组织观点与差异，保留原作者归因和适用范围；开题计划不写成已取得的结果。核验日志与写作指导放内部台账。保留正文中真正影响解释的证据限制，不能为消除提示性表达而强化结论。
